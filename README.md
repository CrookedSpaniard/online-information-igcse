# Online information — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 3 Operating online, Chapter 10 Online information** (book pages 159–165: information sources, search engines, search types and tools, search syntax, fitness for purpose, copyright, plagiarism and the chapter questions). Only these pages are covered.

Each section is explained step by step with interactive simulations, followed by the book's **activity** (where the book has one) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes, including the chapter questions on page 165).

**Part A · Finding information** (pages 159–163)

1. Information sources — primary vs secondary (Table 10.1), sorting simulation, fitness for purpose and audience → Activities (Primary and secondary sources; Table 10.3, auto-marked = chapter question 8) → ✓ Check
2. Search engines — URL in the address bar vs the search field (Figure 10.2), a search engine comparing keywords with a database of web pages, examples, keeping keywords simple, smart personal assistants (Figure 10.3) → ✓ Check
3. Search types and tools — web/images/videos/news/maps (Figure 10.4), filters by date and region (Figure 10.5), image size/colour/type/usage rights (Figure 10.6), autofill, suggested sites and browsing history (Figure 10.7), changing the search engine (Figure 10.8), search engines that track or do not track → ✓ Check
4. Search syntax — AND (+), NOT (-) and phrase matching (“ ”) over a set of made-up pages → ✓ Check
5. Test Part A (chapter questions 1, 2, 4, 7)

**Part B · Using information** (pages 163–165)

6. Fitness for purpose — check five sources for accuracy, age, relevance, reliability and bias; Table 10.2 → ✓ Check
7. Copyright — permission to use, stating the owner or source, the key point (not always allowed even with the owner’s name) → ✓ Check
8. Plagiarism — copy and paste, a live plagiarism checker (shared four-word phrases), changing a few words vs paraphrasing, stating the URL, author and date found → ✓ Check
9. Test Part B (chapter questions 3, 5, 6) · Key terms (searchable)

**Progress that students can share and resume** (same system as the other lessons)

- Saved automatically in the student's browser (`localStorage`, key `oi-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`OI1Z.…`) to carry on with another device.
- Nothing is sent to a server. The search engine, websites, people and articles in the simulations are made up; no real search is done. Speech is only used if the student ticks “Read the answer aloud”.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#syntax` or `#check-fitness`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
